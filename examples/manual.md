# 第一章 文件說明

## 1.1 文件目的

本文件針對測試區平台，提供常用操作場景之完整步驟說明。每個步驟皆可搭配欄位說明、重點截圖與問題排錯，協助使用者熟悉操作。

## 1.2 適用對象

- 測試人員
- 維運人員

# 第二章 操作前置準備

## 2.1 系統需求

| 項目 | 說明 |
|---|---|
| 瀏覽器 | Chrome / Edge |
| 權限 | 需具備平台存取權限 |

## 2.2 登入系統

開啟瀏覽器，於網址列輸入測試區服務網址。

### 2.2.1 輸入帳號密碼

於登入畫面輸入帳號與密碼，點擊登入。

### 2.2.2 確認首頁

登入成功後，系統將顯示首頁，表示登入完成。
